# Giao diện HTML & CSS (Tên dự án của bạn)

Đây là một dự án nhỏ sử dụng HTML và CSS thuần. 

## 🚀 Hướng dẫn cài đặt và chạy thử nghiệm

Dự án này không yêu cầu cài đặt phần mềm bên thứ ba hay môi trường lập trình. Bạn chỉ cần thực hiện 2 bước đơn giản sau:

### 1. Tải code về máy tính
- Bấm vào nút màu xanh **Code** ở góc trên cùng bên phải màn hình GitHub.
- Chọn **Download ZIP** và giải nén thư mục ra máy tính của bạn.
- *(Hoặc nếu bạn dùng Git, hãy mở Terminal và chạy lệnh: `git clone <link_github_cua_ban>`)*

### 2. Chạy dự án
- Mở thư mục vừa giải nén.
- Nháy đúp chuột vào file `heart.html` để mở trực tiếp trên trình duyệt web (Chrome, Edge, Cốc Cốc...).

## 📂 Cấu trúc thư mục
- `heart.html`: Chứa cấu trúc bộ khung giao diện.
- `style.css`: Chứa các dòng lệnh thiết kế màu sắc, hiệu ứng hiển thị.

## 🛠️ Công nghệ sử dụng
- HTML5
- CSS3
